# IMC300 Remote Communication Quick Start Guide

> 来源：074-785-P1A IMC300 Remote Communication Quick Start Guide.pdf

## 简介

本指南旨在概述 Zevision 远程通信协议。所提供的示例命令仅用于远程通信测试。

---

## Zevision 协议

### 概述

**发送到设备：**
{ 起始字符 + 命令数据 } 停止字符

text

**设备响应：**
{ 起始字符 + 命令响应数据 } 停止字符

text

### 起始字符

所有响应都以起始字符开始。起始字符向发送方或接收方发出信号，表示新的传输已开始，并帮助解码传输内容。

**起始字符：** `{`

---

## 协议选项

可以启用选项以使协议更加健壮，减少传输过程中出错的机会。

**发送到设备（启用选项后）：**
{ 起始字符 + 数据长度(2字节 高/低) + 命令数据 + 校验和(1字节，求和，模256，仅数据) } 停止字符

text

**设备响应（启用选项后）：**
{ 起始字符 + 响应数据长度(2字节 高/低) + 命令响应数据 + 校验和(1字节，求和，模256，仅数据) } 停止字符

text

### 长度

传输长度由两个字节的数据（高/低）定义。长度包括消息内的所有命令数据（蓝色阴影部分），不包括起始、停止、长度和校验和字节。长度字节为数值，范围为 1 到 57,000。例如，对于 H01 命令，长度为 3。

### 校验和

校验和是单个字节。校验和的计算方法是对消息内的所有命令数据（蓝色阴影部分）求和，不包括起始、停止、长度和校验和字节（与长度计算相同）。校验和一个字节长，支持无符号模 256。

校验和有助于确保消息内容有效，并检测传输过程中是否丢失了位。例如，`{H02}` 的校验和为十六进制 170，即 `y`。完整的校验和命令为 `{H02y}`。

### 动作类型

动作定义命令将执行的操作。动作为单个 ASCII 字符。

| 动作 | 描述 |
|------|------|
| U | 更新 - 设置配置设置的值 |

| A | 添加 - 向列表添加命令 |
| D | 删除 - 从列表删除命令 |

| E | 回显 - 回显发送的任何数据 |
| S | 状态 - 获取运行时变量的值 |
| R | 远程 - 执行操作 |

### 命令组

命令组定义设置的组织方式。命令组为单个 ASCII 字符。

### 数据

某些命令（如更新和操作命令）需要附加数据。数据通过冒号 ASCII 字符 `:` 与命令分隔。

数据字段中的数据是命令特定的，但可以采用以下形式：

- **数值数据** - 构成数字或浮点数的 ASCII 数字。例如，数值 `78` 或浮点数 `68.553`。
- **字符串数据** - ASCII 字符串。例如，`My Name`（不需要引号）。

### 多条命令

多条命令可以通过分号 `;` 分隔发送。只要总消息长度不超过 57,000 字节，发送的命令数量没有限制。例如：`{SC03;SC04}` 将询问当前速率和当前功率的状态。

## 响应

发送到设备的每条命令都会得到响应。

| 命令回显 (类型, 组, ID...) | 响应状态 (+ 或 -) | 响应错误代码 (可选) (如果错误) (A,B,C...) | : 数据分隔符 (可选，来自查询) | 响应数据 (可选，来自查询) | ; (可选) 命令分隔符 |
|---------------------------|-------------------|-------------------------------------------|-------------------------------|---------------------------|---------------------|

### 命令

完整的命令会在响应中回显。这包括数据分隔符之前的所有内容。这允许对单个命令进行响应。

### 响应状态

响应状态是对命令执行情况的确认。响应状态可以是 `+` 表示肯定，或 `-` 表示否定。

选择响应状态字符为可打印 ASCII 字符，这些字符通常不会在典型的命令/响应中使用。

### 错误响应代码

如果系统返回否定响应，则会返回错误代码，以提供命令失败原因的一些信息。

所有错误代码均为 ASCII 字母：

| 错误代码 | 描述 |
|----------|------|
| A | 非法命令，不支持该命令 |
| B | 非法参数值 |
| C | 校验和错误（仅在启用校验和时） |
| D | 非法格式 |
| F | 状态错误，系统处于错误状态 |
| L | 长度错误（仅在启用长度时） |
| T | 超时，已收到起始字符，但未收到停止字符，且自收到最后一个字符以来已过去 200 毫秒 |

### 数据分隔符

数据分隔符用于标记命令的结束，并区分与命令相关的任何数据。当识别命令时，数据分隔符很有用，因为命令长度可能变化。

数据分隔符字符被选择为可打印 ASCII 字符，通常不会在典型的命令/响应中使用（尽管它可能在逻辑语句和时间输入中使用）。

**数据分隔符：** `:`

### 数据

数据字段仅在查询配置或状态时传输。数据字段中的数据是命令特定的，但可以采用以下形式：

- **数值数据** - 构成数字或浮点数的 ASCII 数字。例如，数值 `78` 或浮点数 `68.553`。
- **字符串数据** - ASCII 字符串。例如，`My Name`（不需要引号）。

### 多条命令

当在同一消息中发送多条命令时，响应由分号 `;` 分隔。每条命令都会收到一个响应。

## 命令集

> ⚠️ **警告**：命令仅用于通信测试。该仪器不得安装在蒸发镀膜工具中。

系统中支持的命令如下：

### 帮助

帮助命令会响应系统中支持的命令的人类可读列表。

| 命令 | 描述 |
|------|------|
| `?` | 显示系统支持的命令 |

### Hello 命令

Hello 命令允许与设备进行简单交互。它们允许设备通信基本配置数据，并验证、发送和接收传输。

| 命令 | 描述 |
|------|------|
| `H01` | 包含产品名称和软件版本号的字符串 |
| `H02` | 包含软件版本号的字符串，每个值用逗号分隔 |

### 回显命令

回显命令用于测试通信接口。传入命令的所有数据都会作为响应发送回来。

| 命令 | 描述 |
