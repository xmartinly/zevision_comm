# Zevision 使用说明

Zevision 通过 RS232 串口或 TCP (以太网) 与 INFICON IMC300 通讯,用于发送协议指令,以及保存、恢复和修改仪器配置。

> 本软件用于通讯测试与配置管理。恢复或修改配置期间请勿操作仪器。

版本 0.10.0 · INFICON · 作者 martin.liang@inficon.com

## 安装

1. 把发布包解压到一个可写的目录 (如 `D:\Zevision`),运行 `Zevision.exe`,不需要安装程序。
2. 程序需要 .NET Framework 4.7.2 或更高版本。Windows 10 (1803 及以上) 和 Windows 11 已内置;Windows 7 SP1、Windows 8.1 或较早的 Windows 10 上启动时提示缺少 .NET Framework 时,运行发布包中的 `dotnet\ndp48-x86-x64-allos-enu.exe` (.NET Framework 4.8 离线安装包,不需要联网,需要管理员权限,安装后可能需要重启),再启动程序。

## 语言

Windows 为中文或区域为中国时界面使用中文,其他情况使用英文。

点 **数据显示** 标题栏右侧的 **EN** / **中** 按钮切换语言:确认后程序会保存配置并自动重新启动 (已连接时会断开,重启后需要重新连接)。选择会保存在 `settings.json` 的 `"language"` 中 (`"zh"`、`"en"`;`"auto"` 为按系统自动选择)。

## 连接

在左侧 **连接设置** 中点 **RS232** 或 **TCP** 标签页,连接时按选中的标签页建立串口或网络连接。

**RS232 (串口)**

1. 用串口线 (或 USB 转串口线) 连接电脑与 IMC300。
2. 选择 **端口**;插拔 USB 转串口线后点端口右侧的刷新按钮。
3. **波特率** 与设备 G1303 一致 (出厂 115200)。数据格式固定为 8N1。
4. **校验和**、**长度字节** 必须与设备 G1304、G1305 的设置一致。

**TCP (以太网)**

1. 用网线连接电脑与 IMC300 的以太网接口,电脑与设备在同一网段。
2. 输入设备的 **IP 地址** (设备 G1402)。端口固定为 2101,无需设置。设备的以太网协议类型 (G1406) 须为 Zevision。
3. **校验和**、**长度字节** 必须与设备 G1407、G1408 的设置一致。
4. TCP 传输比串口快得多,读取完整配置 (约 116 KB) 不再需要约 10 秒。

设置完成后点 **连接**。连接后通讯配置被锁定,断开后才能修改。校验和、长度字节与设备设置不一致时,设备无法识别指令。

鼠标悬停在各配置项上可以看到说明。关闭程序时会自动保存通讯配置,下次打开时恢复。

## 发送指令

- 在底部输入框输入指令后按回车或点 **发送**,如 `H01`。起止符 `{ }`、长度和校验和由程序自动添加。发送时指令部分自动转为大写 (`:` 之后的数据不变,如 `um0101:Aluminium` 发送为 `UM0101:Aluminium`),输入框显示转换后的内容并保留,可修改后再次发送。
- 多条指令用 `;` 分隔,或每行一条 (Shift+回车 换行),合并为一帧发送,如 `QG01;QG1304;QG1305`。程序会逐条显示 "指令 = 数据"。
- 可以手动发送帮助指令 `?`:完整的 `?` 响应约 116 KB,接收约需 10 秒,期间不能发送其他指令。需要保存完整配置时请使用 **保存**。
- 帮助指令 (`?`、`?M` 等) 只有在输入框中发送时才显示。保存、恢复、修改配置时程序读取设备用的帮助指令及其响应不显示,也不保存到通讯数据文件。
- 快捷指令按钮可直接发送常用指令。

### 发送选项 (输入框左侧,连接期间也可修改)

- **显示格式**:HEX (十六进制)、ASCII (文本,默认)、Binary (二进制)。只影响之后收发的数据,已显示的不变。
- **重复发送**:勾选后点 **发送**,程序按 **重复间隔** (100~2000 ms) 重复发送输入框中的指令:每次收到回复 (或超时) 后等待间隔再发下一次。**发送** 按钮变为 **停止**;点 **停止**、取消勾选或断开即停止。重复期间不能发送快捷指令,也不能保存/恢复/修改配置。

## 数据显示

- TX 为发送的数据,RX 为接收的数据,ERR 为错误。
- 停在底部时自动滚动;向上翻看时暂停自动滚动,滚回底部后恢复。
- 选中行后按 Ctrl+C 复制,Ctrl+A 全选。**清空** 清除显示内容和计数。

## 仪器配置

连接后可用,三个按钮:

| 按钮 | 功能 |
|---|---|
| **保存** | 读取设备当前配置 (约 10 秒),保存为 JSON 文件,默认在程序目录的 `recipe` 文件夹 |
| **恢复** | 选择配置文件,与设备当前配置对比,确认后写入不同的项并读回校验 |
| **修改** | 先在左侧下拉框选择来源:**实机数据** — 读取设备当前配置 (约 10 秒) 后修改,只写入设备;**保存的配置** — 选择配置文件后修改,写入设备并保存到该文件 |

- 配置文件带 MD5 校验,手工改动过的文件会被拒绝。请使用 **修改** 功能修改配置。
- 保存、恢复成功后不弹窗,结果记录在数据显示区;出错时 (包括恢复完成但有项无法写入) 弹出提示。

### 修改配置窗口

- **信息** 页:设备信息、工艺状态、对象数量,以及传感器、输出源、输入输出的当前状态。实机数据模式下直接使用刚读取的设备配置,点 **刷新** 获取最新值。
- **设置** 页:按 系统 / 材料 / 膜系 / 膜层 / 工艺 / 传感器 / 输出源 / 输入输出 / 逻辑 分页,页内按对象分组,显示的是设备当前值 (实机数据) 或配置文件中的值 (保存的配置)。
  - 实机数据模式下写入成功后窗口保持打开,可继续修改;不会生成或修改配置文件,需要保存时请用 **保存**。
  - 材料、膜系、膜层、工艺页可以 **新建** 和 **删除** (两种来源都可以):实机数据只修改设备;保存的配置同时修改设备和配置文件,文件立即保存 (新建时编号取设备和文件中都未使用的第一个;删除设备上没有的对象时只从文件中删除;添加/删除工艺的膜层、膜系的预熔/后处理、膜层的膜系前要求设备与文件中该列表的条数相同,否则请先恢复配置):
    - **新建**:按第一个空编号新建 (如已有 M01、M03 时新建 M02),使用设备默认值,完成后重新读取该页并展开新对象,新对象的全部参数自动勾选,可以直接修改后保存。
      - 新建膜系:材料 ID 自动设为第一个材料,膜系的全部参数自动勾选,可以直接修改后保存。没有材料时材料 ID 保持设备默认值。
      - 新建膜层:自动添加一项膜系 (第一个膜系),膜层的全部参数 (名称、膜系、速率、最终厚度) 自动勾选,可以直接修改后保存。没有膜系时不添加 (之后可以用 **添加速率/厚度设置** 添加)。
      - 新建工艺:自动添加第一个膜层,工艺的全部参数自动勾选。没有膜层时不添加。
    - **删除**:每个对象标题右侧的 **删除**,确认后从设备删除,不能撤销。只重新读取当前页。
    - 删除前检查引用 (工艺包含膜层,膜层包含膜系,膜系包含材料):材料被膜系使用、膜系被膜层使用、膜层被工艺使用,或工艺被"设置活动工艺"/"链接工艺"使用时不能删除。提示框列出引用它的设置 (所属对象、名称、ID 和值),请先把这些设置改为其他对象 (或 0 未选择) 并保存后再删除。
    - 工艺的膜层:每个工艺的标题栏上有 **膜层** 下拉框 (列出已有的膜层) 和 **添加** 按钮:选择一个膜层,点 **添加**,立即在设备上添加到列表末尾 (不再确认,加错了用 **×** 删除) (写入后读回校验),并重新读取工艺页。每个膜层行末有 **×**:删除这一个膜层。设备只能删除列表的最后一项,所以删除中间的膜层时,后面的膜层依次前移 (逐项写入并校验),再删除最后一项。
    - 膜系的预熔/后处理:膜系标题右侧有 **+预熔**、**−预熔**、**+后处理**、**−后处理**。**+** 在设备上把一条追加到列表末尾 (使用设备默认值,不再确认);**−** 删除最后一条 (列表为空时不可用)。完成后重新读取膜系页 (约 5 秒),新的一条出现后可以勾选修改。
    - 膜层的速率和厚度:设备上膜层的速率、最终厚度属于膜层中的每个膜系 (膜层 → 膜系列表 → 膜系 ID、速率、最终厚度)。新建的膜层膜系列表为空,所以只有名称;分组中会显示提示和 **添加速率/厚度设置** 按钮 (与标题右侧的 **+膜系** 相同),添加一项后勾选修改它的膜系、速率和最终厚度;**−膜系** 删除最后一项。
    - 以上添加/删除立即作用于设备 (不需要点保存);有勾选的项时不可用。
  - 操作习惯:
    - 直接点击某一项的值即可勾选并进入编辑 (焦点在输入框,文字已全选,直接输入即可替换);用复选框勾选时同样把焦点放到输入框。
    - 快捷键:**Ctrl+S** 保存,**Ctrl+F** 定位到筛选框,**Esc** 关闭窗口 (写入期间为取消写入)。
    - 关闭窗口时,如果有已修改但未保存的项,会先询问是否放弃这些修改;只勾选而没有改动的项不算。
    - 每个类别页记住各自的滚动位置:切换类别页、新建/删除/保存后重新生成页面时,都回到原来的位置。
    - 有勾选的项时不能新建/删除,请先保存或取消勾选;设备必须处于 Ready (空闲) 状态。
    - 程序会核对结果:新建的对象没出现、删除的对象还在或其他对象有变化时会提示。
    - 保存、新建、删除、添加/删除列表项成功后不弹窗,结果显示在窗口底部;出错时弹出提示。
  - 每行为 "名称 (单位) | 值 | ID";鼠标停在行上显示说明、范围或选项。
  - 勾选后才能修改。有固定选项的项 (如开/关、材料) 用下拉框选择,其余直接输入。
  - 数字按原值的小数位数写入 (如 5.89 写成 5.890);时间格式为 时:分:秒,如 0:01:30。
  - 不合法的值显示为红色,鼠标停在上面显示原因;有不合法的值时不能保存。
- 工艺控制、系统时间、通讯设置不在修改范围内。
- 恢复顺序:系统设置 → 材料 → 膜系 → 膜层 → 工艺。设备上已删除的材料、膜系等会被重新创建。
- 恢复确认框会列出将创建的对象、将修改的项和不会写入的项 (含原因)。
- 遇到错误会立即停止,已写入的项不会回滚。
- 每个阶段限时 60 秒;可随时点 **取消**。
- 通讯设置 (G13/G14) 和工艺控制 (C) 不会被恢复。

## 文件位置 (程序目录下)

| 文件 | 内容 |
|---|---|
| `settings.json` | 通讯配置和界面语言 |
| `recipe\*.json` | 仪器配置文件 |
| `logs\error.txt` | 错误记录 (追加写入,超过 5 MB 时另存为 `error.1.txt`) |
| `logs\capture_*.txt` | 打开 "保存通讯数据" 时,连接期间的数据显示内容 (按当时的显示格式),每次通讯后追加,用于诊断通讯问题 |

程序目录不可写时,以上文件改存到 `文档\Zevision\`。

## 常见问题

- **等待响应超时**:检查端口、波特率 (TCP 时检查 IP 地址和端口)、校验和/长度字节是否与设备一致,以及线缆连接。
- **无法连接 IP:2101**:检查网线、IP 地址,以及电脑与设备是否在同一网段;5 秒内无响应即判定连接超时。
- **连接中断**:串口线被拔出或端口被其他程序占用。重新连接即可。
- **再次打开程序没有新窗口**:程序只允许运行一个实例,已打开的窗口会被切换到前台。
- 反馈问题时请附上 `logs\error.txt`;通讯问题请打开 "保存通讯数据" 后重现 (需要逐字节分析时显示格式选 HEX),并附上对应的 `capture_*.txt`。
