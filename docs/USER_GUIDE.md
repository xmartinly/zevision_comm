### 1.1 标识

本文档适用于以下软件：

英文界面对应的用户手册为 ZEV-SUM-01-EN（docs/USER_GUIDE.en.md），内容与本文档一一对应。

### 1.2 系统概述

Zevision 是运行于 Windows 的上位机软件，通过 RS232 串口或以太网（TCP）按 Zevision 协议与 INFICON IMC300 膜厚控制仪通信，用于：

- 发送协议指令，显示收发的数据及解析结果；
- 保存、恢复和修改仪器配置。

本软件用于通信测试与配置管理。恢复或修改配置期间不应操作仪器。

### 1.3 文档概述

本文档依据 GB/T 8567-2006 中软件用户手册（SUM）的内容要求编写，说明软件的安装、启动、操作、数据备份、故障处理和消息。

## 3 软件综述

### 3.1 软件应用

软件提供以下功能：

- 按 RS232 或 TCP 连接一台 IMC300；连接时确认设备应答，并按设备的实际设置确定帧格式（连接时握手）；
- 发送单条或多条协议指令，以 ASCII、十六进制或二进制显示收发的数据；
- 读取设备配置并保存为配置文件；
- 将配置文件恢复到设备；
- 修改设备当前配置或配置文件，新建和删除材料、膜系、膜层、工艺及其列表项。

### 3.5 意外事故以及运行的备用状态和方式

- 连接意外中断时，软件在数据显示区记录原因并回到未连接状态；打开“自动重连”时按 5.3.4 重新连接。中断时正在进行的保存、恢复、修改和重复发送不再继续。
- 恢复配置和保存修改遇到错误时立即停止，已写入设备的项不回滚。
- 保存、恢复、修改的每个阶段限时 60 s，超时后操作取消。
- 关闭“连接时握手”时，软件只打开通道，帧格式按“校验和”“长度字节”开关，不握手、不重发、不发送心跳。该方式用于观察帧格式不一致时设备的原始回答。

### 3.7 帮助和问题报告

- 鼠标指针停留在设置项上时显示简要说明。
- 报告问题时应附上 `logs\error.txt`。报告通信问题时，应打开“保存通讯数据”后重现问题，需要逐字节分析时将“显示格式”设为 HEX，并附上对应的通信数据文件（`logs\<序列号>_<日期>_<时间>.txt`）。
- 链路故障的排查见 ZEV-OPS-01。

## 4 访问软件

### 4.1 首次用户

#### 4.1.1 安装和设置

1. 选择发布包：计算机已安装 .NET Framework 4.7.2 或更高版本（Windows 10 1803 及以上已内置）时使用 `Zevision-<版本>_woDotnet.zip`，否则使用含离线安装包的 `Zevision-<版本>_wDotnet.zip`。
2. 将发布包解压到一个可写的文件夹，例如 `D:\Zevision`。软件不需要安装程序。
3. 运行 `Zevision.exe`。
4. 启动时提示缺少 .NET Framework 时（Windows 7 SP1、Windows 8.1 或 1803 之前的 Windows 10），运行 `_wDotnet` 发布包中的 `dotnet\ndp48-x86-x64-allos-enu.exe`，然后重新启动软件。该安装包不需要联网，需要管理员权限，安装后可能要求重启计算机。

首次启动时界面语言按 5.3.1 确定，其他设置取默认值；退出时设置保存到 `settings.json`。

### 4.2 启动过程

1. 运行 `Zevision.exe`。
2. 软件恢复上次保存的设置，数据显示区显示就绪信息，状态栏显示 `未连接`。

软件已在运行时再次启动，不打开新窗口，已打开的窗口切换到前台。

### 4.3 停止和挂起工作

- 关闭主窗口即退出软件。处于连接状态时，软件先取消正在进行的配置操作，停止重复发送和自动重连，断开连接，关闭通讯数据文件，然后退出。
- 退出时保存当前设置。
- 切换界面语言时软件重新启动（见 5.3.1）。

### 5.2 约定

- 界面元素的名称写在中文引号中，如“连接”；按界面原文书写。
- 指令、设置项 ID、文件名、路径和软件显示的消息原文写在代码格式中，如 `H01`、`G1304`、`settings.json`。
- “设备”指所连接的 IMC300。
- “帧格式”指帧中是否带校验和与长度字节。RS232 接口由设备的 G1304（校验和）、G1305（长度）决定，以太网接口由 G1407、G1408 决定，两者相互独立。
- “单击”指用鼠标左键单击。

### 5.3 处理过程

#### 5.3.1 界面语言

Windows 显示语言为中文或区域格式为中国时，界面使用中文；其他情况使用英文。

切换语言的步骤：

1. 单击“数据显示”标题栏右侧的“EN”（英文界面中为“中”）。
2. 在确认框中确认。

软件保存设置后自动重新启动；处于连接状态时先断开，重启后需重新连接。所选语言保存在 `settings.json` 的 `language` 项中，取值为 `zh`、`en` 或 `auto`（按系统选择）。

#### 5.3.2 建立连接

RS232 连接的步骤：

1. 用串口线或 USB 转串口线连接计算机与 IMC300。
2. 单击“RS232”标签页。
3. 选择“端口”。插拔 USB 转串口线后，单击端口右侧的刷新按钮重新扫描。
4. 选择“波特率”，应与设备 G1303 一致（出厂值 115200 bit/s）。可选 9600、19200、38400、57600、115200 bit/s，数据格式固定为 8N1。
5. 单击“连接”。

TCP 连接的步骤：

1. 用网线连接计算机与 IMC300 的以太网接口，计算机与设备应处于同一网段。
2. 单击“TCP”标签页。
3. 输入设备的“IP 地址”（设备 G1402）。端口固定为 2101。设备的以太网协议类型（G1406）应为 Zevision。
4. 单击“连接”。

连接参数：

- “响应超时 (ms)”可选 500、1000（默认）、2000、5000 ms，为空闲超时：发送后或最近一次收到数据后，超过该时间没有新数据即判定超时，大响应持续传输时不超时。
- “校验和”“长度字节”对应设备的 G1304、G1305（TCP 为 G1407、G1408）。打开“连接时握手”时，连接后软件按设备的实际设置调整这两个开关。
- TCP 连接 5 s 内无响应即判定连接失败。
- TCP 传输快于 RS232：经 RS232 读取完整配置（约 116 KB）约需 10 s，经 TCP 用时明显较短。

连接期间“连接设置”和“协议选项”被锁定，断开后才能修改。

“校验和”“长度字节”“保存通讯数据”按 RS232 和 TCP 分别保存，切换标签页时开关显示该连接方式上次的设置；“连接时握手”“自动重连”两种连接方式共用。退出时全部保存。

#### 5.3.3 连接时握手

“连接时握手”默认打开。打开时软件的处理如下：

1. 连接后发送 `H01` 确认设备应答，按设备的实际设置确定帧格式。与开关不一致时，软件改用设备的设置，更新开关，并显示 `设备的帧格式与协议选项不同,已改用设备的设置。`。
2. 读取设备型号（G03）和帧格式设置。型号不是 IMC300，或设备报告的设置与实际使用的帧格式不一致时，软件显示提示并继续连接。
3. 以上全部成功后，状态栏显示 `已连接 …`，数据显示区显示连接参数和 `设备: Zevision IMC300 …`。

握手过程中的收发不显示。设备没有应答或无法识别帧格式时，软件不建立连接，显示 `握手失败: …` 及原因。

连接期间（握手打开时）：

- 传输出错（超时、帧错误、设备回答校验和错误 C、长度错误 L、超时 T）时，软件自动重发，最多 2 次，每次显示 `第 1/2 次重发 …`。含追加（A）、删除（D）、执行动作（R）的指令不重发。
- 连接空闲时每 5 s 发送一次不显示的心跳（`H01`）。设备连续 3 次没有应答时，软件判定连接中断。拔掉的串口线和网线均可据此发现。
- 在输入框中发送并被设备接受的帧格式设置指令（如 `UG1304:1`）生效后，软件按新的帧格式重新握手并更新开关，显示 `已改用设备的新帧格式: …`。重新握手失败时软件断开连接。
- 设备回答 F（状态不允许）时，软件读取并显示设备当前状态，如 `设备当前状态 (C09): Process`。软件不自动切换设备状态。

“连接时握手”关闭时，软件只打开通道，帧格式按开关，不握手、不重发、不发送心跳，也不查询设备状态。修改了设备的帧格式设置时，软件只显示提示，应断开并修改“协议选项”后重新连接。

#### 5.3.4 自动重连

“自动重连”默认关闭。打开时，连接意外中断后软件按以下间隔重新连接，直到成功：1 s、2 s、4 s、8 s、16 s、32 s，之后每 60 s 一次。每次重新连接都重新握手。

- 等待期间状态栏显示 `连接中断,x 秒后第 n 次重连 …`，状态指示点为主题色，“连接设置”和“协议选项”保持锁定。
- 单次重连失败显示 `第 n 次重连失败: …`，不记入错误日志。
- 重连成功后显示 `已重新连接。`。
- 单击“断开”停止自动重连，显示 `已停止自动重连。`。
- 连接中断时正在进行的保存、恢复、修改和重复发送不再继续。

#### 5.3.5 断开连接

单击“断开”。正在进行的一次收发完成后连接关闭，重复发送停止，状态栏显示 `未连接`。保存、恢复或修改进行期间“断开”不可用。

#### 5.3.6 发送指令

1. 在指令输入框中输入指令，如 `H01`。
2. 按 Enter 键或单击“发送”。

规则：

- 起止符 `{ }`、长度字节和校验和由软件添加。
- 发送时每条指令的命令部分转为大写，`:` 之后的数据不变，如 `um0101:Aluminium` 发送为 `UM0101:Aluminium`。输入框显示转换后的内容并保留，可修改后再次发送。
- 多条指令用 `;`（或全角 `；`）分隔，或每行一条（Shift+Enter 换行），合并为一帧发送，如 `QG01;QG1304;QG1305`。软件逐条显示 `指令 = 数据`。
- 帮助指令 `?` 可手动发送。完整的 `?` 响应约 116 KB，经 RS232 接收约需 10 s，期间不能发送其他指令。分组帮助（如 `?M`）只返回该组。保存完整配置应使用“保存”（5.3.9）。
- 帮助指令（`?`、`?M` 等）只在从输入框发送时显示。保存、恢复、修改配置时软件读取设备所用的帮助指令及其响应不显示，也不保存到通讯数据文件。
- 快捷指令按钮发送以下常用指令：`H01`、`H02`、`QG01`，以及当前连接方式的帧格式设置查询（RS232 为 `QG1304`、`QG1305`，TCP 为 `QG1407`、`QG1408`）。

#### 5.3.7 发送选项

发送选项位于指令输入框左侧，连接期间可修改，退出时保存。

- “显示格式”：HEX（十六进制，每行 32 字节）、ASCII（文本，不可打印的字节显示为 `<XX>`，默认）、Binary（二进制，每行 16 字节）。只影响之后收发的数据，已显示的内容不变。
- “重复发送”：勾选后单击“发送”，软件按“重复间隔 (ms)”重复发送输入框中的指令；每次收到回复或超时后等待一个间隔再发送下一次。间隔可选 100、200、500、1000（默认）、1500、2000 ms。“发送”按钮变为“停止”；单击“停止”、取消勾选或断开连接即停止。重复期间不能发送快捷指令，也不能保存、恢复或修改配置。

#### 5.3.8 数据显示

- TX 表示发送的数据，RX 表示接收的数据，ERR 表示错误，INFO 表示信息。错误行同时记入 `logs\error.txt`。
- 显示位置处于底部时自动滚动；向上滚动时暂停自动滚动，滚回底部后恢复。
- 标题栏显示 TX（发送的帧数）、RX（接收的帧数）和 ERR（错误指令数）。错误指令为没有得到成功响应的指令：设备回答否定响应（`-A`、`-B` 等）的指令，以及发出后没有有效响应（超时、响应无效）的帧中的全部指令。重发后成功的指令、握手和心跳不计入。ERR 大于 0 时以错误色显示。
- 选中行后按 Ctrl+C 复制，Ctrl+A 全选。单击“清空”清除显示内容和 TX、RX、ERR 计数。
- 显示区最多保留 20000 行，超出时删除最早的 2000 行。
- 打开“保存通讯数据”时，连接期间显示的内容（按当时的显示格式）先保存在内存中，超过 50 KB、断开连接（含连接中断）或退出程序时写入 `logs` 目录中的通信数据文件。文件名为设备的系统序列号（G06）、连接的日期和时间（到分钟），如 `XXXXXXXX_20261021_1337.txt`；未启用“连接时握手”或设备未返回序列号时，序列号部分为 `unknown`。同一分钟内再次连接时追加到同一文件。一个文件超过 30 MB 时，后续内容写入在原文件名后加 `_1`、`_2`… 的文件（如 `XXXXXXXX_20261021_1337_1.txt`）。该开关在连接时生效。程序异常终止时，内存中尚未写入的内容丢失。

#### 5.3.9 保存配置

1. 连接设备。
2. 单击“保存”。软件读取设备当前配置（经 RS232 约 10 s）。
3. 在保存对话框中确认文件名和位置。默认位置为程序目录下的 `recipes` 文件夹，默认文件名为 `IMC300_yyyyMMdd_HHmmss.json`。

保存成功后不弹出消息框，结果记录在数据显示区。读取阶段限时 60 s，可单击“取消”中止。

#### 5.3.10 恢复配置

1. 连接设备。设备应处于 Ready（空闲）状态，型号应与文件一致。
2. 单击“恢复”，选择配置文件。
3. 软件读取设备配置并与文件对比，确认框列出将创建的对象、将修改的项和不写入的项（含原因，如引用的材料不存在、坩埚号超出输出源的坩埚数量）。
4. 确认后软件写入，并逐项读回校验。

规则：

- 写入顺序：系统设置、材料、膜系、膜层、工艺。设备上已删除的材料、膜系、膜层、工艺按文件重新创建，列表中缺少的条目在末尾追加。
- 只写入与设备不同的项。设备上有而文件中没有的对象和条目不删除。
- 遇到错误立即停止，已写入的项不回滚。
- 读取阶段和执行阶段各限时 60 s；确认框打开期间不计时。可随时单击“取消”。
- 通讯设置（G13、G14）和工艺控制（C）不恢复。
- 固件版本与文件不同时，确认框显示提示。
- 恢复成功后不弹出消息框，结果记录在数据显示区。出错时，或恢复完成但有项无法写入时，弹出消息框。

#### 5.3.11 修改配置

##### 5.3.11.1 选择数据来源并打开修改窗口

1. 在“修改”左侧的下拉框中选择数据来源：
   - “实机数据”：读取设备当前配置（经 RS232 约 10 s，限时 60 s）后修改，只写入设备，不生成或修改配置文件；
   - “保存的配置”：选择配置文件后修改，写入设备，全部成功后同时保存该文件。
2. 单击“修改”。

配置文件带 MD5 校验，手工改动过的文件被拒绝。修改配置文件应使用本功能。

工艺控制、系统时间和通讯设置不在修改范围内。只能查询的设置项不显示。

##### 5.3.11.2 “信息”页

“信息”页显示设备信息、RS232 设置、工艺状态（C09～C21）、对象数量，以及传感器、输出源、输入、输出的位置和状态。数据来源为“实机数据”时，显示刚读取的设备配置；为“保存的配置”时，打开窗口时从设备读取。单击“刷新”从设备重新读取。对象数量在新建、删除后不自动更新，单击“刷新”更新。

##### 5.3.11.3 “设置”页

“设置”页按类别分页：系统、材料、膜系、膜层、工艺、传感器、输出源、输入输出、逻辑。页内按对象分组，组标题包含对象名称；组数不超过 3 的页默认展开。显示的值为设备当前值（实机数据）或配置文件中的值（保存的配置）。

表 6  “设置”页的控件

| 控件 | 作用 |
|---|---|
| 行 | `名称 (单位) \| 值 \| ID`；鼠标指针停留时显示 ID、范围或选项和设备说明 |
| 复选框 | 勾选后可修改该行；取消勾选时值还原 |
| “全选” | 勾选本组所有可见的项 |
| “清除” | 取消勾选本组所有项，值还原 |
| “全部展开”“全部收起” | 展开或收起当前页的所有组 |
| 筛选框 | 按 ID、名称、设备说明或值筛选（Ctrl+F）；匹配的组不超过 20 个时自动展开 |
| “保存” | 将勾选的项写入设备并读回校验（Ctrl+S） |
| “取消写入” | 写入期间取消（Esc） |
| “关闭” | 关闭窗口（Esc） |

修改值的规则：

- 单击某一项的值即勾选该项，焦点移到输入框且文字全选，输入内容即替换原值；用复选框勾选时焦点同样移到输入框。
- 有固定选项的项（如开/关、材料）用下拉框选择，其余项在输入框中输入。当前值不在选项中时显示为 `(未知)`；引用的对象不存在时显示为 `(不存在)`，该值保留。
- 膜系的坩埚号：下拉框为 `0 - 任意` 和 1 至该膜系所选输出源的坩埚数量（输出源的“坩埚数量”；未选择输出源时为 1）。同一次保存中修改了输出源时，写入前按新的输出源检查，超出坩埚数量时不写入并提示。
- 数字按原值的小数位数写入，如 5.89 写入为 5.890。时间格式为 `H:MM:SS`，如 `0:01:30`。
- 不合法的值显示为红色，鼠标指针停留时显示原因；存在不合法的值时不能保存。协议保留字符始终检查；类型和范围只在值被修改后检查。

保存修改的步骤：

1. 勾选并修改设置项。
2. 单击“保存”或按 Ctrl+S，在确认框中确认。
3. 软件检查设备型号和 Ready 状态，按顺序写入并逐项读回校验。

保存结果：

- 全部成功后，勾选的项取消勾选。数据来源为“实机数据”时窗口保持打开，可继续修改，页面按新值刷新（组标题、引用下拉框中的名称同时更新）；数据来源为“保存的配置”时同时保存配置文件并关闭窗口。
- 失败时配置文件不变，窗口保持打开，勾选的项保持勾选。
- 写入期间不能关闭窗口。
- 关闭窗口时存在已修改未保存的项，软件询问是否放弃；只勾选而未改动的项不计。
- 每个类别页记住各自的滚动位置；切换类别页或页面重新生成后回到原位置。

##### 5.3.11.4 新建和删除对象

材料、膜系、膜层、工艺页提供新建和删除功能，两种数据来源均可使用：

- 数据来源为“实机数据”时只修改设备；
- 数据来源为“保存的配置”时同时修改设备和配置文件，文件立即保存。新建时编号取设备和文件中均未使用的第一个编号；删除设备上不存在的对象时只从文件中删除。

新建（单击页面上的“新建材料”等按钮）：

1. 在确认框中确认。
2. 软件按第一个空编号新建（如已有 M01、M03 时新建 M02），使用设备默认值，然后重新读取该页并展开新对象，新对象的全部参数自动勾选，可修改后保存。

新建对象的默认引用：

- 新建膜系：材料 ID 设为编号最小的材料；没有材料时保持设备默认值。
- 新建膜层：添加一项膜系（编号最小的膜系），膜层的名称、膜系、速率、最终厚度自动勾选；没有膜系时不添加，之后可用“添加速率/厚度设置”添加。
- 新建工艺：添加编号最小的膜层；没有膜层时不添加。

删除（单击对象标题右侧的“删除”）：

1. 在确认框中确认。删除不可撤销。
2. 软件从设备删除该对象，只重新读取当前页。

删除前软件检查引用关系（工艺包含膜层，膜层包含膜系，膜系包含材料）。材料被膜系使用、膜系被膜层使用、膜层被工艺使用，或工艺被“设置活动工艺”“链接工艺”使用时不能删除；提示框列出引用该对象的设置（所属对象、名称、ID 和值）。应先将这些设置改为其他对象（或 0 未选择）并保存，再删除。

##### 5.3.11.5 列表项的添加和删除

- 工艺的膜层：工艺组标题上有“膜层”下拉框（列出已有膜层）和“添加”按钮。选择膜层并单击“添加”，软件在设备上将其添加到列表末尾（不再确认），写入后读回校验，并重新读取工艺页。每个膜层行末有“×”按钮，单击后删除该膜层。设备只能删除列表的最后一项，删除中间的膜层时，其后的膜层依次前移（逐项写入并校验），再删除最后一项。
- 膜系的预熔和后处理：膜系组标题右侧有“+预熔”“−预熔”“+后处理”“−后处理”按钮。“+”在设备上将一条（设备默认值）追加到列表末尾，不再确认；“−”删除最后一条，列表为空时不可用。完成后软件重新读取膜系页（约 5 s），新增的条目可勾选修改。
- 膜层的速率和厚度：设备上膜层的速率和最终厚度属于膜层中的每个膜系条目（膜层、膜系列表、膜系 ID、速率、最终厚度）。新建膜层的膜系列表为空，组中显示提示和“添加速率/厚度设置”按钮（与标题右侧的“+膜系”相同）；添加一项后勾选并修改其膜系、速率和最终厚度。“−膜系”删除最后一项。

数据来源为“保存的配置”时，添加或删除工艺的膜层、膜系的预熔和后处理、膜层的膜系前，设备与文件中该列表的条数应相同；不同时应先恢复配置。

##### 5.3.11.6 共同规则

- 新建、删除和列表项的添加、删除立即作用于设备，不需要单击“保存”。
- 存在勾选的项时上述功能不可用，应先保存或取消勾选。
- 设备应处于 Ready（空闲）状态。
- 软件核对结果：新建的对象未出现、删除的对象仍存在或其他对象发生变化时显示提示。
- 保存、新建、删除、列表项变更成功后不弹出消息框，结果显示在窗口底部；出错时弹出消息框。

### 5.5 数据备份

- 仪器配置文件保存在程序目录下的 `recipes` 文件夹（程序目录不可写时为 `文档\Zevision\recipes`）。备份时复制该文件夹。
- 配置文件为 UTF-8 JSON，带 MD5 校验；手工改动后的文件被拒绝加载。
- 1.1.0 之前的版本使用 `recipe` 文件夹。第一次保存或打开配置文件时，软件将 `recipe` 文件夹改名为 `recipes`；`recipes` 已存在时两个文件夹均保留。改名失败（如其中的文件被其他程序打开）时旧文件保留在 `recipe` 中，可在打开对话框中选择。
- `settings.json` 保存连接设置、发送选项和界面语言。损坏时软件使用默认值并在数据显示区报告，退出时覆盖该文件。
- 文件位置的完整列表见附录 A。

### 5.6 错误、故障和紧急情况时的恢复

表 7  常见故障及处理

| 现象 | 原因 | 处理 |
|---|---|---|
| `握手失败: 设备没有应答 H01` | 端口、波特率或 IP 地址不正确；线缆未连接；设备未开机 | 检查端口、波特率（TCP 时检查 IP 地址）、线缆和设备电源 |
| `握手失败: 无法识别设备的帧格式` | 多为波特率不正确 | 核对设备 G1303；需要查看设备发送的原始数据时，关闭“连接时握手”后连接 |
| `等待响应超时` | 端口、波特率、IP 地址不正确；帧格式与设备不一致；线缆问题 | 检查端口、波特率（TCP 时检查 IP 地址）、校验和与长度字节设置以及线缆 |
| `无法连接 <IP>:2101` | 网线、IP 地址或网段不正确 | 检查网线、IP 地址，以及计算机与设备是否处于同一网段 |
| `连接中断: …` | 串口线被拔出、端口被其他程序占用，或设备连续 3 次未应答心跳 | 重新连接；需要自动恢复时打开“自动重连” |
| 断开后立即重新连接时提示端口访问被拒绝 | Windows 尚未释放串口 | 等待 1 s～2 s 后重新连接 |
| `设备当前状态 (C09): Process` | 设备正在运行工艺，拒绝修改（F） | 设备回到 Ready 状态后再操作 |
| 配置文件被拒绝加载 | 文件被手工改动，MD5 校验失败 | 使用未改动的文件；修改配置应使用“修改”功能 |
| 再次启动软件时没有新窗口 | 软件只允许运行一个实例 | 使用已切换到前台的窗口 |

恢复配置中途出错时，已写入的项不回滚，应检查原因后重新执行恢复。
